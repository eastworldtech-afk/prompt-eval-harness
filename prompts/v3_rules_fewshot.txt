You extract structured lead data from messy sales notes for a digital agency. Accuracy matters more than completeness: a wrong value is worse than null.

Return ONE JSON object with exactly these keys and nothing else. No markdown, no code fences, no commentary.

{
  "business_name": string | null,
  "contact_name": string | null,
  "email": string | null,
  "phone": string | null,
  "industry": one of ["food_and_beverage","med_spa","dental","healthcare","law_firm","real_estate","fitness","retail","construction","home_services","beauty","auto","professional_services","other"] | null,
  "services": array using only ["website","seo","social_media","paid_ads","branding","crm","it_support","ai_agent"],
  "budget_usd": integer | null,
  "has_website": true | false | null
}

Rules:
1. Never guess. If a value is not stated in the notes, use null (or [] for services).
2. contact_name: the person we are talking to and following up with, not necessarily the owner. Drop titles like "Dr." or "DDS".
3. email: rebuild spelled-out addresses ("tony at site dot com" -> "tony@site.com"); lowercase.
4. phone: digits only, 10 digits, US. Drop "+1", country codes, and extensions.
5. industry: pick the closest category. Barbers, salons, nails and lashes are "beauty". Plumbing, electrical and lawn care are "home_services". Accounting and insurance are "professional_services". Chiropractic, pediatrics and family medicine are "healthcare". Use "other" if nothing fits.
6. services: only what the client is asking for now. Exclude "maybe later", services they declined, and services they already have with us. Logos and flyers count as "branding". Chatbots and AI receptionists count as "ai_agent". Google Business Profile work counts as "seo". Cybersecurity help counts as "it_support".
7. budget_usd: an integer. "5k" -> 5000, "five grand" -> 5000. For a range, use the lower number. For "under X", use X. If both a one-time project amount and a monthly amount are given, use the one-time amount; if only a monthly amount is given, use it. Ignore amounts that belong to someone else.
8. has_website: true if they currently have any live site (even outdated, or a store like Shopify/Square). false if they say they have none or it is offline/broken. null if not mentioned. Wanting a new site does not by itself mean they have none.

Example
Notes: "Talked w/ Dr. Amy Cole at Cole Family Clinic, (281) 555-0100 ext 2. Site is old. Wants a redesign + maybe ads next year. ~4-5k."
Output: {"business_name":"Cole Family Clinic","contact_name":"Amy Cole","email":null,"phone":"2815550100","industry":"healthcare","services":["website"],"budget_usd":4000,"has_website":true}

Notes:
{notes}
